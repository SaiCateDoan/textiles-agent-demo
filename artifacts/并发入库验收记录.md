# 并发入库与恢复验收

日期：2026-11-02。范围为共享本地磁盘的单机入库可靠性改造，没有引入多机队列或外部数据库。

## 自动验证

- `uv run --frozen pytest -q --junitxml=artifacts/pytest.xml`：94 项通过，33.77 秒。
- `npm.cmd --prefix frontend run build`：通过。
- 真实 LanceDB 创建 document_id 标量索引和 cosine IVF_FLAT 索引，查询原始向量命中对应记录。
- 10 万条合成积压任务只启动 2 个文档工作协程和 1 个维护协程；领取后 99998 条仍保存在数据库中，退出后任务全部恢复可领取。此项不处理 10 万份文件。
- 覆盖队列容量、并发独占领取、过期租约拒绝发布、全局视觉槽位/RPM预算、解析进程超时、部分视觉结果恢复、嵌入缓存、失败重新索引/编辑保留旧版本、上传幂等、分页、临时数据回收及关闭服务时迟到租约归还。
- 视觉和聊天模型在这些自动测试中使用替身；不作为真实 DeepSeek 质量验收。

## 真实并发导入

独立服务使用 8101 端口及独立数据目录，共享本机已下载的模型权重，不修改原知识库。

命令：`uv run --frozen python scripts/benchmark_ingestion.py --url http://127.0.0.1:8101 --documents 40 --concurrency 12 --rows 32 --timeout 240`。

| 指标 | 结果 |
|---|---|
| 原件 | 40 份明确标注的模拟 CSV，每份 32 行 |
| 并发上传 | 12 |
| 实际执行 | HTTP 上传、解析子进程、BGE、SQLite FTS5、LanceDB |
| 就绪 | 40/40 |
| 总耗时 | 21.8 秒 |
| 上传确认 P95 | 78 毫秒 |
| 健康探测 | 177 次，0 次错误 |
| 健康响应 P95 / 最大 | 32 / 约 93 毫秒 |
| 背压 | 12 次，重试成功 |
| 测试文档清理 | 全部完成 |

该轮不调用 DeepSeek；这是一次本机小规模实测，不证明十万份复杂文档的端到端吞吐。机器报告在本机 `artifacts/ingestion-load.json`，按仓库规则不提交。

## 现有资料升级

升级前通过 SQLite 备份接口保存元数据副本，位于本机 `.cache/backups/`，不纳入 Git。升级后只读校验：15 份文档均有有效发布版本，81 个分块对应 81 条全文索引，版本不匹配 0，缺失图片关联 0。原有 DOCX 样本修改未覆盖。

## 验收限制

Edge 的本地工作台页面被保存的浏览器权限策略拒绝观察；后续独立验收服务重启被自动审批拒绝，原因为 `blocked by policy`。因此本轮没有浏览器内视觉验收，也没有完成额外的真实 DeepSeek 多模态/图表/控件对话复验，未通过其他浏览器或间接方式绕过。

现有工作台服务已重启，前后端端口保持为 8000 / 5173。部署配置、参数和尚存的生产边界见 [design.md](../docs/design.md)。
