# 导入验收材料

01～03 和 05～08 均为项目人工编造的纺织业务数据，仅供软件验收，不得作为工厂真实记录或生产配方。

建议通过前端一次选择 01、02、03、06 导入，再单独导入 07 验证混合 PDF。分块状态依次为等待处理、解析/OCR、向量索引、索引就绪。可打开文档检查分块并编辑。

| 文件 | 用途 | 预期 |
|---|---|---|
| 01_MES生产日报_模拟.csv | 12 行生产日报 | 机台平均不良率 A=1.25%、B=2.10%、C=0.85%；算术平均而非产量加权 |
| 02_定型工况实验_模拟.csv | 15 行历史工况 | 温度150～185°C；车速固定25 m/min；可生成图表和滑块 |
| 03_染整工艺单_模拟.md | 中文工艺与异常说明 | TX-202610-003 经向缩水4.2%，待复检 |
| 04_前处理知识_公开来源摘要.txt | 自行概括的公共知识 | 保留原站链接与访问日期 |
| 05_扫描质检报告_模拟.png | 中文图片 | OCR 提取质检结果 |
| 06_纯扫描质检报告_模拟.pdf | 只有图片的PDF | 没有文本层；OCR 提取批次及克重146 g/m2 |
| 07_含图工艺附件_模拟.pdf | 正文文字层+报告图片 | 同时提取正文与图内OCR |
| 08_坯布参数_模拟.pdf | 有文本层PDF | 直接提取中文正文 |

公共来源：

- [CottonWorks Dyeing Preparation](https://cottonworks.com/learning-hub/dyeing/dyeing-preparation/)，发布机构 Cotton Incorporated；04为项目自行概括。
- [NPTEL Dyeing applications with reactive dyes](https://archive.nptel.ac.in/content/storage2/courses/116104046/31.pdf)，可自行获取用于本机阅读、检索和格式测试，另存为 `09_NPTEL_Reactive_Dyeing_Public.pdf`。版权及使用条件由原发布者确定，不受本项目 MIT 协议覆盖；原件已被 Git 忽略，不随公开仓库分发。自动回归测试不依赖此文件。

原始文件保存在此目录，不会自动加入知识库，必须通过上传接口或前端导入。tests/expected.json 保存可独立校验的数值。
